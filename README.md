# Ubuntu-starter

Скрипт для настройки Ubuntu 24.04 после установки.

## Установка

```bash
sudo apt install git -y
git clone https://github.com/Genkinston/Ubuntu-starter.git
cd Ubuntu-starter
```

## Использование

```bash
bash bash/start.sh
```

Интерактивное меню:

```
[0] update system
[1] base soft
[2] extra soft
[3] flatpak and soft
[4] games
[5] appimage
[6] virtual machine soft
[7] docker cli
[8] programming
[ALL] install all
[9] exit
```
